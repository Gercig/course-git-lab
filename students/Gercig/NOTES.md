
# Заметки по Git

1. Git хранит историю в папке .git
2. Три зоны: рабочая директория, staging, репозиторий
3. git status показывает состояние файлов
4. git add кладёт изменения в область подготовки
5. git commit создаёт снимок

# Заметки по Git Flow

1. main — только релизы
2. develop — интеграция фич
3. feature/* — отдельные задачи, от develop
4. release/* — подготовка релиза
5. hotfix/* — срочные фиксы прода, от main
## Таблица Git Flow

| Ветка | Откуда | Куда | Зачем |
|-------|--------|------|-------|
| `main` | — | принять из `release/*` и `hotfix/*` | боевая линия, только релизы |
| `develop` | от `main` при старте проекта | принять из `feature/*`, `release/*`, `hotfix/*` | интеграция следующего релиза |
| `feature/*` | от `develop` | в `develop` | одна задача / фича |
| `release/*` | от `develop` | в `main` и обратно в `develop` | подготовка релиза, багфиксы, версия |
| `hotfix/*` | от `main` | в `main` и в `develop` | срочный фикс прода |
